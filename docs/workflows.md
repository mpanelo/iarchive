# Local inventory and image review workflows

Import registers an existing local download without invoking cloud authentication. Index hashes every regular file independently and exports a local byte inventory. Audit proposes exact, similar, and dark image review groups, preserves decode errors, and saves previews separately. Complete pending dependency and platform checks before scanning a real archive.

For a stable local snapshot, stop concurrent writing by the downloader, confirm iPhones finished uploading separately, and identify Personal/Shared Library coverage. Those confirmations are not recorded or proven by this build. Use a fresh cycle ID for an intentionally changed archival snapshot; existing archive folders remain untouched.

Run `import`, `index`, `audit`, `report`, and `export-manifest` as described in [the CLI guide](CLI.md). Inventory and image reports describe saved local work and keep replica and cloud coverage at **NOT VERIFIED**. Use [replication and deep verification](replication.md) for raw copies, frozen source bindings, safe retries and recoverable manifests. Replica reports distinguish local byte verification from physical backup independence and cloud coverage. Use `review --cycle ID` with the same state directory to compare saved previews and record keep/flag/defer decisions; see [browser review](review.md). These notes do not change media or establish backup completion. Quarantine, media restore and cloud removal remain unavailable.
